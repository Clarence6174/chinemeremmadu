About

The Vibe

Freelance ML Engineer. I work best alone — mostly taking chaotic data and quietly making it make sense. No fluff, just structure.

The Work

I build models that actually learn and pipelines that don't fall over. Ideas out of the notebook, into production, without the usual headache.

The Focus

Living somewhere between end-to-end ML infra, optimizing code until it's stupid-fast, and dropping open-source side quests whenever I feel like it.

The Downtime

Screen closed, outside with a juice, unplugged. Though it's still pretty wild that we can teach math to do things.

Stack & Skills

Core Languages

  • Python — Build, train, and experiment with machine learning models and data pipelines.
  • C++ — Write high-performance, low-latency code and interface directly with GPU hardware architectures.
  • Rust — Build memory-safe, ultra-fast data processing tools and high-throughput backend services.
  • Scala / Java — Process massive distributed datasets at scale using big data infrastructure.

Machine Learning & Deep Learning

  • PyTorch — Build, train, and manipulate the mathematical tensors that make up deep learning models.
  • TensorFlow & Keras — Design, prototype, and train deep neural networks using scalable, production-ready APIs.
  • Scikit-Learn — Build classic baseline models for classification, regression, and clustering.
  • Hugging Face Transformers — Load, customize, and fine-tune state-of-the-art open-source LLMs and vision models.
  • LangChain — Orchestrate complex chains, agents, and memory systems for LLM-powered applications.

Data Infrastructure & Management

  • PostgreSQL — Design relational databases, store application data, and write complex queries for structured datasets.
  • Docker — Package ML models with their exact environments for reproducible deployment anywhere.
  • AWS — Rent powerful GPU clusters and manage cloud-based machine learning infrastructure.
  • Ubuntu / Linux — Run production servers, manage filesystems, and interface directly with hardware drivers.

Development & CI/CD Tools

  • Git & GitHub — Manage codebase versions, collaborate on large systems, and track code changes.
  • GitHub Actions — Automate testing, linting, and continuous integration pipelines for ML code.
  • VSCode — Write, debug, and test code across multiple programming languages.
  • Postman — Test API endpoints, verify model inference response times, and debug data payloads.

Machine Learning Specializations

  • Supervised & Unsupervised Learning — Train models on labeled data for predictions, or cluster unlabeled data to find hidden patterns.
  • Retrieval-Augmented Generation (RAG) — Connect LLMs to external databases for accurate, context-aware answers without hallucinations.
  • Prompt Engineering — Design, optimize, and evaluate precise text prompts to maximize LLM performance and reliability.
  • ETL Processes — Build data pipelines that Extract raw data, Transform it for training, and Load it into data stores.

Mathematical Foundations

  • Linear Algebra & Geometry — Format datasets into multi-dimensional matrices and tensors for neural network layers.
  • Calculus — Optimize model training using gradients, partial derivatives, and backpropagation techniques.
  • Probability & Statistics — Analyze data distributions, validate model performance, and evaluate significance tests.

Core Engineering & Reasoning

  • Data Analysis & Retrieval — Clean messy datasets, extract relevant features, and query production information stores.
  • Logical & Algebraic Thinking — Design efficient code logic and break down complex system requirements.
  • Critical Evaluation — Diagnose why a model is failing, identify system bottlenecks, and audit data bias.
  • Continuous Learning & Research — Read and implement latest AI research papers into production systems.

Professional & Business Skills

  • Business Acumen — Align machine learning engineering priorities with core product goals and company revenue drivers.
  • Effective Communication — Explain complex technical trade-offs to non-technical cross-functional stakeholders.
  • Languages — English & French — collaborate across global, distributed engineering teams.
